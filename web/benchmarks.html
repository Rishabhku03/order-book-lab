Method and limitations

Warm-up precedes measured passes. Each measurement runs in a separate process on the recorded logical CPU. File cache is uncontrolled and input checksums are read before timing. Workload sizes change both order count and available price levels. Memory is process working set/RSS, not exact allocator bytes. Every variant must end in the same state.

Local laptop scheduling, power and temperature can change results. The timer-pair baseline is included in the raw latency results; it is not subtracted. No market-profitability or network-latency claim is made.
